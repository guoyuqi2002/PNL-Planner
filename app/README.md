# Channel P&L Planner (app)

Wails v2 desktop application: Go backend (compute engine, Excel import/export,
settlement processing) + Vue 3 / Element Plus frontend.

See the [repository README](../README.md) for the full feature description, build
instructions, and the synthetic-data notice for `master_data.json` / `code_mapping.json`.

Quick start:

```bash
wails dev     # development
wails build   # production build
```
